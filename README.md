# Bazaarino

A responsive Persian e-commerce website built with HTML5 and CSS3.

## Overview

Bazaarino is a front-end practice project created to demonstrate core HTML and CSS skills through the implementation of an e-commerce user interface. The website features a right-to-left (RTL) layout, responsive pages, and a CSS-based dark mode.

## Features

- Responsive layouts for desktop, tablet, and mobile
- Persian language and RTL support
- Product listing and product detail pages
- Registration form UI
- Mobile navigation and sidebar filters implemented with CSS
- Light and dark themes based on system preferences
- Local Vazirmatn font
- Reusable CSS variables and organized stylesheets
- BEM-inspired CSS class naming

## Pages

- Home page
- Product listing page
- Product detail page
- Registration page

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Custom Properties
- Git and GitHub

## Getting Started

Clone the repository:

bash
git clone git@github.com:hami-karimi/.bazarino.git

Open the project folder in VS Code and launch `index.html` using Live Server, or open the file directly in your browser.
